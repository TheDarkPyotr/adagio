---
title: Network Awareness
description: Adagio automatically adapts sync behaviour to metered connections, battery state, and blocked SSIDs.
---

Adagio monitors your network type and power source so that syncing never runs up an unexpected data bill or drains your battery during a meeting.

## Detect metered connections

Adagio queries **NetworkManager** to determine whether the active connection is flagged as metered (for example, a mobile hotspot or a tethered LTE connection). When a metered connection is detected, sync pauses automatically.

Override this behaviour in **Settings** → **Network** → **Sync on metered connections**.

## Adapt to battery state

On battery power Adagio reduces the sync polling frequency to conserve energy. Full-speed polling resumes automatically when AC power is detected.

Override this in **Settings** → **Network** → **Sync on battery**.

## Block specific SSIDs

Add network names (SSIDs) that should never trigger sync — useful for untrusted public Wi-Fi, expensive hotel networks, or roaming connections that NetworkManager does not automatically flag as metered.

**Settings** → **Network** → **Blocked SSIDs** → **Add**

Or use the CLI:

```bash
adagio network block-ssid "Coffee Shop Free WiFi"
```

To remove a blocked SSID:

```bash
adagio network unblock-ssid "Coffee Shop Free WiFi"
```

## Review the policy options

| Policy setting | Option | Behaviour |
|----------------|--------|-----------|
| `on_metered` | `allow` | Sync proceeds normally on metered connections |
| `on_metered` | `throttle` | Sync runs at a reduced bandwidth cap |
| `on_metered` | `pause` | Sync halts until the connection is no longer metered |
| `on_battery` | `allow` | Sync proceeds at full frequency on battery |
| `on_battery` | `throttle` | Sync polls less frequently on battery |
| `on_battery` | `pause` | Sync halts until AC power is restored |

<Callout type="info">All network-awareness overrides are available in **Settings** → **Network**.</Callout>

## Override network rules manually

**Sync Now** in the tray menu always fires an immediate full sync cycle regardless of any active network-awareness rules. Use this when you know the transfer is safe and you need the latest files now.
