---
title: Bandwidth Controls
description: Throttle upload and download speeds per account.
---

Adagio lets you cap upload and download speeds independently for each Nextcloud account, so syncing never saturates your connection.

## Set per-account limits

Open **Settings** → **Accounts** → *select account* → **Bandwidth** to configure speed limits.

| Setting | Default | Valid range | Remove limit |
|---------|---------|-------------|--------------|
| Upload limit | Unlimited | 10 KB/s – 1 GB/s | Enter `0` |
| Download limit | Unlimited | 10 KB/s – 1 GB/s | Enter `0` |

Changes take effect immediately for any in-progress transfers.

## Understand token-bucket throttling

Adagio uses a **token-bucket** algorithm to enforce limits:

- A bucket is maintained for uploads and a separate one for downloads.
- Each bucket refills continuously at the configured rate (e.g. 500 KB/s fills 500 KB of tokens per second).
- Every WebDAV read or write operation draws tokens from the corresponding bucket proportional to the bytes transferred.
- When the bucket is empty the transfer sleeps until enough tokens accumulate, naturally capping throughput to the configured rate.

This approach allows short bursts up to the bucket capacity while keeping sustained throughput at or below the limit.

## Understand what is throttled

Throttling applies to the **propagation stage only** — the part of the pipeline that moves file data via WebDAV. The journal (inotify event capture) and the reconciler (diff computation) are not affected and continue to run at full speed regardless of bandwidth limits.
