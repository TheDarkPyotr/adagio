---
title: Conflict Resolution
description: Understanding and resolving sync conflicts in Adagio.
---

A conflict happens when the same file is modified both locally and on the Nextcloud server between two sync cycles and neither version is a direct descendant of the other.

## Understand what triggers a conflict

Conflicts arise when:

- You edit a file while offline, and another client (or the web UI) saves a different version in the same window.
- Two devices both modify the same file before either has had a chance to sync.
- A remote change lands during a long-running local write operation.

Adagio detects conflicts during the reconciler stage by comparing local modification timestamps against the ETag returned by the server.

## Choose a resolution policy

Configure the conflict policy per pair in **Settings** → **Pairs** → *select pair* → **Conflict policy**.

| Policy | Behaviour |
|--------|-----------|
| **Ask** (default) | Pauses sync for that file only and opens the conflict wizard so you can decide |
| **Keep Local** | Automatically overwrites the remote version with the local copy — no prompt |
| **Keep Remote** | Automatically overwrites the local version with the remote copy — no prompt |

<Callout type="info">The Ask policy pauses only the conflicted file. The rest of the pair continues syncing normally while you decide.</Callout>

## Resolve a conflict with the wizard

<Steps>
  <Step>
    A notification appears in the system tray indicating a conflict on a specific file.
  </Step>
  <Step>
    Click the notification to open the conflict wizard.
  </Step>
  <Step>
    The wizard displays both versions side by side with their last-modified timestamps and file sizes. Review the differences to decide which version to keep.
  </Step>
  <Step>
    Select **Keep local version**, **Keep remote version**, or **Keep both** and click **Resolve**.
  </Step>
</Steps>

## Keep both versions

Selecting **Keep both** writes the remote version alongside your local copy with a timestamped suffix:

```
report.pdf
report.conflict.20260512T143000.pdf
```

Both files then sync normally. You can merge or delete the conflict copy at your leisure.

## Review conflict history

Every conflict event — including which policy was applied and which version was kept — is recorded in the activity log. Open it from **Settings** → **Activity** or via the tray menu.
