---
title: End-to-End Encryption
description: Encrypt sync pairs with Nextcloud E2EE v2 — the server never sees your file contents.
---

Adagio implements Nextcloud's E2EE v2 protocol. Every file in an encrypted pair is sealed with AES-128-GCM before it leaves your device; the server stores only UUID-named ciphertext blobs.

## Understand what E2EE protects

| Component | Detail |
|-----------|--------|
| File encryption | AES-128-GCM per-file |
| Key protection | RSA-2048 key pair |
| Key backup | BIP-39 24-word mnemonic |
| Server visibility | UUID-named ciphertext only — no filenames, no contents |

## Prepare the server

<Callout type="danger">Nextcloud server-side encryption (SSE) must be disabled before E2EE will work. Running both simultaneously corrupts metadata. Execute the following on the server before enabling E2EE on any pair.</Callout>

```bash
docker exec --user www-data nextcloud php occ encryption:disable
```

Confirm the output reads `Encryption disabled`.

## Initialise E2EE for a pair

<Steps>
  <Step>
    Go to **Settings** → **Pairs** and select the pair you want to encrypt.
  </Step>
  <Step>
    Click **Enable E2EE**.
  </Step>
  <Step>
    Adagio generates an RSA-2048 key pair, submits a PKCS#10 CSR to the server, and creates an encrypted metadata folder on Nextcloud. This takes a few seconds.
  </Step>
  <Step>
    A 24-word BIP-39 mnemonic is displayed. Write it down and store it in a safe place before proceeding.
  </Step>
  <Step>
    Click **Done**. E2EE is now active — subsequent syncs for this pair will encrypt all file content before upload.
  </Step>
</Steps>

<Callout type="warning">The mnemonic is the only way to recover your encryption keys if you lose access to this device. Back it up before clicking Done. It will not be shown again.</Callout>

## Understand what the server stores

After E2EE is enabled, Nextcloud holds only:

- UUID-named binary blobs (the encrypted file content)
- An encrypted metadata document that only your client can decrypt

The actual filenames, directory structure, and file contents are never transmitted in plaintext.

## Recover keys from a mnemonic

If you reinstall Adagio or lose your local key material, recover access to an E2EE pair using your mnemonic:

**Settings** → **E2EE** → **Recover from mnemonic**

Or via the CLI:

```bash
adagio e2ee pair --mnemonic "word1 word2 word3 ... word24"
```

<Callout type="info">VFS on-demand is not compatible with E2EE on the same pair. If a pair has E2EE enabled, the Virtual filesystem option will be unavailable for that pair.</Callout>
