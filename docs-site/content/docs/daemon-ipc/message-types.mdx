## DaemonRequest variants

All requests are serialised as `{"id": N, "method": "<snake_case>", ...fields}`.

### Ping

Health-check; returns version and uptime.

```json
{"id": 1, "method": "ping"}
```

### StopDaemon

Request graceful shutdown (30 s drain).

```json
{"id": 2, "method": "stop_daemon"}
```

### SetStartAtLogin

```json
{"id": 3, "method": "set_start_at_login", "enabled": true}
```

### GetStatus

Return the current engine-level sync status.

```json
{"id": 4, "method": "get_status"}
```

### TriggerSync

```json
{"id": 5, "method": "trigger_sync", "pair_id": "abc123"}
```

### PauseSyncAll / ResumeSyncAll

```json
{"id": 6, "method": "pause_sync_all"}
{"id": 7, "method": "resume_sync_all"}
```

### GetActivityLog

```json
{"id": 8, "method": "get_activity_log", "limit": 50, "filter": null}
```

### SearchFiles

```json
{"id": 9, "method": "search_files", "query": "report", "limit": 20}
```

### GetSectionCounts

```json
{"id": 10, "method": "get_section_counts", "pair_id": null}
```

### GetErrorItems

```json
{"id": 11, "method": "get_error_items", "pair_id": "abc123"}
```

## DaemonResponse variants

All responses are `{"id": N, "result": <payload>}` or `{"id": N, "error": {...}}`.

| Variant | Payload shape |
|---------|---------------|
| `Pong` | `{"version": "0.1.0", "uptime_secs": 3600}` |
| `Unit` | `{}` |
| `Status` | JSON object with sync engine state |
| `Pairs` | Array of pair objects |
| `Pair` | Single pair object |
| `Accounts` | Array of account objects |
| `Account` | Single account object |
| `SyncedFiles` | Array of file-tree entries |
| `Strings` | Array of strings (e.g. blocked SSIDs) |
| `RemoteTree` | Array of remote file entries |
| `ActivityLog` | Array of log entries |
| `ErrorItems` | Array of error entries |
| `Conflicts` | Array of conflict objects |
| `DismissedCount` | `{"dismissed_count": N}` |
| `Users` | Array of Nextcloud user objects |
| `Share` | Share details object |
| `DaemonStatus` | `{"running": true, "uptime_secs": 3600, "connection_state": "ok"}` |

## DaemonEvent variants (push)

Push events are `{"event": "<snake_case>", "payload": {...}}` sent on subscription connections.

| Event | Payload |
|-------|---------|
| `conflict_detected` | `{"pending_count": N}` |
| `conflict_resolved` | `{"id": "...", "pending_count": N}` |
| `sync_status_changed` | `{"status": "syncing\|idle\|error", "pair_id": "..."}` |
| `transfer_progress` | `{"pair_id": "...", "path": "...", "bytes_done": N, "bytes_total": N}` |
| `shutting_down` | `{"reason": "..."}` |
