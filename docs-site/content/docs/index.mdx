Adagio is a Nextcloud sync client for Linux with on-demand VFS, end-to-end encryption, bandwidth throttling, and network-awareness built in.

## What Adagio does

Adagio runs as a background daemon that keeps your local folders in sync with any Nextcloud server. The desktop UI and the `adagio-cli` tool both connect to the daemon over a Unix socket, so you can manage everything from a terminal or the system tray without interrupting active syncs.

The three main processes are:

- **adagio-daemon** — sync engine, VFS driver, IPC server. Runs as a systemd user service.
- **adagio-desktop** — Tauri-based UI. Connects to the daemon over the Unix socket at `~/.config/adagio/daemon.sock`.
- **adagio-cli** — command-line interface for scripting, status checks, and headless environments.
