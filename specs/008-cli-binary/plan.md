# Implementation Plan: CLI Binary

**Branch**: `008-cli-binary` | **Date**: 2026-05-30 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/008-cli-binary/spec.md`

---

## Summary

Add a standalone `adagio` binary that connects to the running `adagio-daemon` via the
existing `adagio-ipc` `DaemonClient` and exposes all 22 user-facing daemon operations
as ergonomic CLI subcommands. Two output modes: human-readable tables (default) and
`--json` for scripting. The CLI never runs its own sync engine.

**One new workspace crate**: `crates/adagio-cli/` (binary, depends only on
`adagio-ipc` and `clap`).  
**One migration**: `platform_config_dir()` moves from `adagio-daemon/src/main.rs`
into `adagio-ipc/src/transport.rs` so both daemon and CLI can call it.  
**One new workspace dep**: `clap = { version = "4.5", features = ["derive"] }`.

---

## Technical Context

**Language/Version**: Rust stable 1.78+ (edition 2021)

**Primary Dependencies**:
- `adagio-ipc` — `DaemonClient`, `DaemonRequest`, `platform_config_dir()` (after migration)
- `clap v4.5` with `derive` feature — new workspace dep
- `serde_json` — already in workspace (for `--json` output)
- `tokio` — already in workspace (async `main`)

**Storage**: None — CLI is stateless; all state is in the daemon.

**Testing**: `cargo test --lib -p adagio-cli` for unit tests; `quickstart.md` for
integration validation.

**Target Platform**: Linux, macOS, Windows.

**Performance Goals**:
- Every command completes in < 2 s when daemon is already running (SC-001).
- `adagio sync` auto-starts daemon and completes in < 8 s (SC-002).

**Constraints**:
- CLI MUST NOT depend on `adagio-core`, `adagio-nextcloud`, or `adagio-desktop`.
- All output to stdout; all errors to stderr.
- `--json` flag is global and applies to every subcommand.
- Exit codes: 0/1/2/3 strictly (see contract).

**Scale/Scope**: ~600 lines of new Rust code. One new crate.

```text
Cargo.toml                        ← ADD clap = { version = "4.5", features = ["derive"] }
                                  ← ADD crates/adagio-cli to workspace members

crates/adagio-ipc/src/transport.rs ← MIGRATE platform_config_dir() from daemon here;
                                    ← re-export pub fn platform_config_dir() -> Result<PathBuf>

crates/adagio-daemon/src/main.rs   ← REPLACE inline platform_config_dir() with call to
                                    ← adagio_ipc::transport::platform_config_dir()

crates/adagio-cli/                 ← NEW binary crate
  Cargo.toml                       ← deps: adagio-ipc, clap, tokio, serde_json
  src/
    main.rs                        ← #[tokio::main]; parse Cli; call run(); process::exit
    cli.rs                         ← Cli, Commands, PairsCommand, AccountsCommand,
                                   ←   ConflictsCommand, DaemonCommand (clap derive)
    run.rs                         ← run(cli: Cli) → Result<(), CliError>; dispatch to handlers
    handlers/
      status.rs                    ← adagio status
      sync.rs                      ← adagio sync
      pause_resume.rs              ← adagio pause / resume
      activity.rs                  ← adagio activity
      pairs.rs                     ← adagio pairs list/add/remove
      accounts.rs                  ← adagio accounts list/remove
      conflicts.rs                 ← adagio conflicts list/resolve/dismiss
      daemon.rs                    ← adagio daemon start/stop/status
    output.rs                      ← print_table() and print_json() helpers
    error.rs                       ← CliError enum → exit code mapping

docs/adr/
  011-no-table-crate.md            ← NEW
  012-platform-config-dir-migration.md ← NEW
```

**Structure Decision**: One handler file per subcommand group; shared `output.rs` for
the two rendering modes. `run.rs` is the top-level dispatcher — thin, just a `match`
that calls each handler.

## Implementation Phases

### Phase 1: Setup

**Deliverables**:
1. `docs/adr/011-no-table-crate.md` — rationale for hand-rolled output
2. `docs/adr/012-platform-config-dir-migration.md` — rationale for moving the function
3. Add `clap = { version = "4.5", features = ["derive"] }` to `[workspace.dependencies]`
4. Add `adagio-cli` to workspace `members`
5. Create `crates/adagio-cli/Cargo.toml` and stub `src/main.rs` (compiles, prints "TODO")
6. Migrate `platform_config_dir()` to `adagio-ipc/src/transport.rs`; update daemon to call it

**Checkpoint**: `cargo check -p adagio-cli -p adagio-daemon` passes.

### Phase 2: Core infrastructure

**Deliverables**:
1. `cli.rs` — all clap derive types: `Cli`, `Commands`, and all nested enums
2. `error.rs` — `CliError { DaemonError(String), Unreachable(String) }` with `exit_code()` method
3. `output.rs` — `fn print_json(v: &serde_json::Value)` and `fn print_table_row(cols: &[(&str, &str)])` helpers
4. `run.rs` — empty match dispatch skeleton (returns `Ok(())` for every arm)
5. `main.rs` — parse `Cli`, call `run()`, map `CliError` to `process::exit(code)`

**Tests** (failing first):
- `cli_parses_status_command` — `Cli::parse_from(["adagio", "status"])` → `Commands::Status`
- `cli_global_json_flag` — `Cli::parse_from(["adagio", "--json", "status"])` → `json=true`
- `cli_json_after_subcommand` — `Cli::parse_from(["adagio", "status", "--json"])` → `json=true`
- `cli_parses_conflicts_resolve` — `parse_from(["adagio", "conflicts", "resolve", "abc", "--keep", "local"])` → correct variant
- `exit_code_daemon_err_is_2` — `CliError::DaemonError("x".into()).exit_code() == 2`
- `exit_code_unreachable_is_3` — `CliError::Unreachable("x".into()).exit_code() == 3`

### Phase 3: US1 — Status command

**Deliverables**:
1. `handlers/status.rs` — `pub async fn run_status(client, json: bool)`:
   - calls `client.request(DaemonRequest::GetStatus)` 
   - JSON mode: `print_json(&result)`
   - Human mode: print table of `status` field + derived pair info
2. Wire `Commands::Status` in `run.rs`

**Tests** (failing first):
- `status_human_prints_table` — stub client returning known JSON, assert stdout contains "idle"
- `status_json_is_valid_json` — assert `print_json` output parses without error

---

### Phase 4: US2 — Sync, pause, resume

**Deliverables**:
1. `handlers/sync.rs` — `pub async fn run_sync(client, pair_id: Option<String>, json: bool)`:
   - With `pair_id`: `TriggerSync { pair_id }`
   - Without: `TriggerSync { pair_id: "" }` (daemon syncs all when empty — add
     `TriggerSyncAll` variant OR reuse `TriggerSync` with empty string; verify daemon behavior)
   - Print "Sync triggered" / `{"ok": true}`
2. `handlers/pause_resume.rs` — `PauseSyncAll` / `ResumeSyncAll`
3. Wire all three in `run.rs`
4. Activity handler: `handlers/activity.rs` — `GetActivityLog { limit, filter }`

**Tests**:
- `sync_with_pair_id_sends_correct_request` — verify `DaemonRequest::TriggerSync { pair_id }` sent
- `sync_without_pair_id_sends_trigger_all` — verify all-pairs variant sent

### Phase 5: US3 — Conflicts

**Deliverables**:
1. `handlers/conflicts.rs`:
   - `run_conflicts_list(client, pair_id: Option<String>, json: bool)` — calls `ListConflicts`; if no pair_id, calls for all pairs (needs `ListPairs` first then loops)
   - `run_conflicts_resolve(client, id, keep, json)` — calls `ResolveConflict { id, side: keep }`
   - `run_conflicts_dismiss(client, json)` — calls `DismissAllConflicts`
2. Wire in `run.rs`

**Tests**:
- `conflicts_list_no_pair_id_queries_all_pairs` — assert loop over pairs
- `conflicts_resolve_keep_local_sends_correct_side`
- `conflicts_dismiss_sends_dismiss_all`

### Phase 7: US5 — Daemon lifecycle
