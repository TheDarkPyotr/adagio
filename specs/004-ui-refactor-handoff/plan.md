# Implementation Plan: UI Refactor — Design Handoff Implementation

**Branch**: `004-ui-refactor-handoff` | **Date**: 2026-05-25 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/004-ui-refactor-handoff/spec.md`

## Summary

Replace the existing functional-but-unstyled Svelte UI with the editorial design defined in `handoff/DESIGN.md`. This is a frontend-first refactor: 30+ new React 18 components across 7 user stories (design system, chrome/sidebar shell, file browser, onboarding wizard, activity feed, share dialog, system tray). Backed by 4 new Tauri IPC commands (`search_users`, `create_share`, `get_palette`, `set_palette`) and minor extensions to existing commands (`get_activity_log` filter param, `ActivityEntryDto` kind field). All existing Rust sync engine code is unchanged.

---

## Technical Context

**Language/Version**: TypeScript 5.x + React 18.x (frontend); Rust stable 1.75+ (backend, unchanged)

**Primary Dependencies**:
- Frontend: `@tauri-apps/api ^2`, `@tauri-apps/plugin-shell ^2`, `react ^18.3.1`, `react-dom ^18.3.1`; devDeps: `@vitejs/plugin-react ^4.3.1`, `@types/react ^18.3.1`, `@types/react-dom ^18.3.1`
- Fonts: Geist, Geist Mono (from `geist` npm package), Instrument Serif italic (self-hosted .woff2)
- CSS: CSS custom properties from `handoff/source/tokens.css` (no new CSS framework)
- New Rust deps: none (uses existing `reqwest`, `serde`, `tauri`, `tracing`)

**Storage**: `config.json` (existing, extended with `palette` field); no new storage

**Testing**: React-compatible testing framework (TBD — `@testing-library/react` or Vitest + jsdom; deferred pending framework stabilization); existing `cargo test` for Rust

**Target Platform**: Linux, macOS, Windows (Tauri 2)

**Performance Goals**:
- File browser renders 500 files within 1 second (SC-002)
- Palette switch completes within 300ms (SC-005)
- All UI transitions 120–150ms ease-out; prefers-reduced-motion → ≤1ms

**Constraints**:
- No internet dependency: fonts must be self-hosted
- CSP: `default-src 'self'; style-src 'self' 'unsafe-inline'` — no CDN font loads
- All shortcut handlers in-app only (no `tauri-plugin-globalShortcut`)
- No toasts, no modals for sync events — all state in chrome/sidebar/table

**Scale/Scope**: 30+ React components, 4 new Tauri commands, 1 new Nextcloud API module (`sharing.rs`), 1 new Tauri command module (`prefs.rs`)
