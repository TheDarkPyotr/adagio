# Contract: Release Pipeline

**Feature**: 017-release-packaging
**Type**: CI/CD Pipeline Contract

---

## Trigger Contract

| Trigger | Condition | Outcome |
|---------|-----------|---------|
| `push` tag `v*.*.*` | Any semver tag | Full pipeline: test → build → publish stable release |
| `push` tag `v*.*.*-rc*` / `-beta*` / `-alpha*` | Pre-release suffix | Full pipeline → publish as pre-release |
| `workflow_dispatch` | Manual with optional `tag` input | Same as tag push |

## Job Dependency Contract

```
test ──┬──► build-linux ──┐
       └──► build-macos ──┤──► publish
```

- `publish` MUST NOT run if any preceding job fails (FR-007)
- `build-linux` and `build-macos` run in parallel after `test` passes

## Artifact Contract

All artifacts produced per release:

| File | Platform | Format |
|------|----------|--------|
| `adagio_${VERSION}_amd64.deb` | Ubuntu/Debian | Debian package |
| `adagio-${VERSION}-1.x86_64.rpm` | Fedora/RHEL | RPM package |
| `adagio_${VERSION}_amd64.tar.gz` | Linux generic | Tarball with binary + README |
| `Adagio_${VERSION}_universal.dmg` | macOS | Disk image |
| `checksums.txt` | All | SHA-256 of all artifacts |

Each package MUST contain:
- `adagio-desktop` binary
- `adagio-daemon` binary (via Tauri `externalBin`)
- `adagio-cli` binary (via Tauri `externalBin`)

## Version Enforcement Contract

The release workflow MUST verify before building:
```
CARGO_VERSION == TAG_VERSION (without 'v' prefix)
```
If mismatch: pipeline FAILS with diagnostic message. No artifact is built.

## Desktop Entry Contract (Linux)

The bundled `.desktop` file MUST contain:

```ini
[Desktop Entry]
Type=Application
Name=Adagio
GenericName=Cloud File Sync
Comment=Sync files with your Nextcloud server
Exec=adagio-desktop
Icon=adagio
Terminal=false
Categories=Network;FileTransfer;
StartupNotify=true
```

All fields validated against freedesktop.org Desktop Entry Specification 1.5.

## Icon Contract (Linux)

Icons MUST be installed at the following XDG sizes under `/usr/share/icons/hicolor/<size>x<size>/apps/adagio.png`:

`16`, `24`, `32`, `48`, `64`, `128`, `256`, `512` px

Source: `icons/png/adagio-icon-<size>.png` (already present in repo).

## GitHub Release Page Contract

Published release page MUST include:
1. Version tag (e.g. `v0.1.0`)
2. Release date (auto from GitHub)
3. Human-readable markdown changelog (generated by `git-cliff`)
4. Download links labelled by platform and format
5. `checksums.txt` attachment

Stable releases (`v*.*.*`) MUST be marked `latest`. Pre-releases MUST NOT replace `latest`.
