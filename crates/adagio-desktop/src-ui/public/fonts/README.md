# Self-hosted fonts

Geist and Geist Mono were copied from the `geist` npm package (OFL-1.1 license).

**Instrument Serif Italic** must be downloaded manually from Google Fonts:
- URL: https://fonts.google.com/specimen/Instrument+Serif
- Download the **Italic** variable or static woff2, place it here as:
  `InstrumentSerif-Italic.woff2`

Without this file the serif accent phrases (e.g., tray "Up to *date*", onboarding tagline)
will fall back to Georgia italic.
