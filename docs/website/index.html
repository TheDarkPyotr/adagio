What's in 0.1.0.

First public release
01 · Virtual file system

On-demand, by default.

A FUSE3 filesystem shows every file as a placeholder. Nothing touches your disk until you open it. Pin to keep offline, evict to reclaim space.

02 · Encryption

Your keys. Not ours.

Per-folder end-to-end encryption seals files before they leave your machine. Adagio never sees your content. Neither does your provider.

03 · Onboarding

Connected in a minute.

Paste your server, authorise over Nextcloud OAuth2, pick a folder. Adagio detects the rest.

04 · Sync daemon

Always-on, never loud.

A background daemon syncs continuously with live status and a Sync Now button that shows its ETA.

05 · Network aware

Knows where you are.

Throttle bandwidth up and down. Back off on metered connections, on battery, or on specific Wi-Fi networks.

06 · Multi-account

More than one cloud.

Switch accounts instantly — favorites, tags, pairs and counts are scoped per account. A GNOME tray keeps it a glance away.

Features
  • Nextcloud OAuth2 account setup
  • VFS on-demand files — FUSE3 PathFilesystem
  • VFS pin / evict, coexistence, platform wiring
  • Per-folder end-to-end encryption + UI
  • Bandwidth throttling, up and down
  • Network awareness — metered / battery / SSID

Fixes & hardening
  • jemalloc eliminates RSS growth (AC-3)
  • FUSE unprivileged mount + disk reconciliation
  • Atomic metadata sync preserves local state
  • Account switcher scopes data per account
  • Auth-on-first-sync passes raw app password
  • E2EE runner lifecycle — cancel on remove
  • Daemon registered in journal DB on startup
  • Inline sync errors in the pair row
Platform

  • FUSE3 required for virtual files
  • GNOME tray integration
  • Cross-platform CI pipeline
  • Windows build — in progress
  • macOS — planned
